# Beta feedback

I use the current build in everyday play, and its features are working well. Reports from other players help find anything that behaves differently on other setups.

## Known issues

- **Combat:** some controller interactions are restricted by the game; report any trouble.
- **UI errors:** UI errors have been reported with several addons enabled; cause not isolated. Please include error text.

## Reporting a problem

Open an issue on [GitHub Issues](https://github.com/CraigTheWorst/Baggler/issues) and include:

- **What happened** and what you expected instead.
- **Steps to reproduce**, as clearly as you can (for example: “open bags at a vendor, press X on a stack”).
- **Input:** keyboard/mouse, controller, or both.
- **Client version** (for example 1.60.1.71037) and Baggler version.
- **Other addons** you have enabled — optional, but helpful.
- **Error text**, if an error appeared (from the game, BugSack or `/baggler incidents`).

Please don't attach full logs, saved-variable files or screenshots showing character, guild or account names. A short copied excerpt is enough; [troubleshooting](TROUBLESHOOTING.md) explains what to leave out.

Ideas and feature requests are welcome too.
